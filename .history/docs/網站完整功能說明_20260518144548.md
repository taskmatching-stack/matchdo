# MatchDO 合做 — 網站完整功能說明

本文件為全站功能總覽，涵蓋公開頁、發案者、廠商／接案者、管理員後台與相關技術要點。  
**相關文件**：操作手冊 `docs/user-manual.md`、網站地圖 `docs/sitemap.md`、種子廠商 `docs/種子廠商入駐操作手冊.md`。

---

## 一、網站定位與角色

| 角色 | 說明 | 主要入口 |
|------|------|----------|
| **訪客** | 未登入使用者，可瀏覽首頁、圖庫、廠商、方案等公開頁 | `/`、`/custom/`、`/remake/`、`/vendors.html` |
| **發案者（客戶）** | 有需求、要發包的使用者 | `/client/dashboard.html` |
| **廠商／接案者** | 提供訂製／改製服務；可建立廠商資料、上傳作品與素材 | `/client/manufacturer-dashboard.html`（廠商控制台） |
| **管理員** | 後台管理用戶、種子廠商、會員方案、點數、金流、AI 設定等 | `/admin/index.html` |

註：廠商相關頁面（控制台、作品、素材、詢價）位於 **`/client/`** 路徑下，由「建立廠商資料」後的同一帳號使用。

## 二、公開功能（無需登入或登入後共用）

### 2.1 首頁與靈感牆

- **路徑**：`/`（實際內容為 `iStudio-1.0.0/index.html`）
- **功能**：靈感牆展示「用戶設計」「廠商對照圖」「系列／資料夾」等作品；可依類型（全部／設計圖／對照圖／系列圖）、分類、關鍵字篩選；點卡片可看詳情、再設計、找廠商訂製。
- **獨立 URL**：每張作品有獨立網址 `/inspiration/{type}/{id}`，利於分享與 SEO。

### 2.2 登入與註冊

- **登入**：`/login.html`
- **註冊**：`/register.html`
- 支援 Email／密碼；若啟用第三方登入則依站方設定。註冊後可選角色（發案者／接案者）。

### 2.3 客製產品（訂製流程）

| 路徑 | 說明 |
|------|------|
| `/custom/` | 客製首頁：找訂製廠商、進入圖庫、進入產品設計 |
| `/custom/gallery.html` | 客製圖庫：依分類／關鍵字瀏覽作品，可「再設計」或「找廠商訂製」 |
| `/custom-product.html` | 產品設計：選擇訂製分類、輸入描述、上傳參考圖或**「從廠商素材庫選」**參考圖（可按訂製主分類篩選廠商素材）、AI 生成設計圖；可儲存至數位資產、找廠商訂製；**引用廠商素材時會記錄引用來源**，儲存後可於詳情查看 |
| `/custom-product.html?tab=scene-sim` | 實境模擬：上傳環境／人物圖＋產品圖，合成情境圖（扣點） |
| `/custom-product.html?tab=pattern-extract` | 圖樣提取：上傳圖片，AI 提取圖樣（可無縫拼接），依輸出解析度扣點 |

- **廠商素材庫**（vendor_assets）：設計時可「從廠商素材庫選」按鈕 → 篩選該訂製主分類下所有廠商上傳的素材 → 點擊素材後新增至參考圖區；一般使用者看不到**種子廠商**的素材（僅管理員可見），避免未同意前之智慧財產權問題。

### 2.4 再製／改裝

| 路徑 | 說明 |
|------|------|
| `/remake/` | 再製首頁 |
| `/remake-product.html` | 再製設計：必傳參考圖、選再製分類、輸入描述，AI 產生改裝設計圖；可儲存或找廠商 |

### 2.5 廠商列表與廠商詳情

- **廠商列表**：`/vendors.html`（依分類、搜尋找廠商）
- **廠商詳情**：`/vendor-profile.html?id={廠商 UUID}` — 顯示廠商名稱、介紹、聯絡方式、作品集、素材（若有）；可「用此廠商版型設計」進入設計頁並帶入該廠商 ID

### 2.6 會員方案與點數

- **會員方案**：`/subscription-plans.html` — 各級訂閱方案（月費、每月點數、接案分類數等）
- **我的點數**：`/credits.html`（需登入）— 點數餘額、儲值、訂閱、消費紀錄；點數用於 AI 生圖、實境模擬、圖樣提取等

### 2.7 其他公開頁

- **關於**：`/about.html`
- **聯絡**：`/contact.html`
- **作品系列／資料夾**：`/custom/collection.html?slug=xxx`（由媒體牆或圖庫進入）

## 四、廠商（接案者）功能

需登入並**建立廠商資料**後，方可使用廠商相關頁面。

### 4.1 廠商控制台與資料

| 路徑 | 說明 |
|------|------|
| `/client/manufacturer-dashboard.html` | 廠商控制台總覽 |
| `/profile/contact-info.html` | 聯絡資訊編輯（與廠商資料中的聯繫與社群一致） |

- 廠商資料含：名稱、介紹、地點、**聯繫與社群**（Email、電話、LINE、官網、Facebook、Instagram 等）、分類、認證標章。

### 4.2 作品與素材

| 路徑 | 說明 |
|------|------|
| `/client/manufacturer-portfolio.html` | 我的廠商作品：對照圖／系列圖的上傳、編輯、刪除、資料夾管理 |
| `/expert/vendor-assets.html` | **我的設計素材庫**：參考圖、設計範本、材料樣本等上傳管理；依訂製主分類分類；訂製者設計時可直接選取 |

- **種子廠商**：由平台代為建立、代為上傳素材；廠商本人可**查看**作品與素材，**不得編輯／上傳／刪除**；其素材僅**管理員**可見，一般使用者看不到。轉為付費後即可自行編輯，素材也對所有人顯示。

### 4.3 詢價與其他

| 路徑 | 說明 |
|------|------|
| `/client/manufacturer-inquiries.html` | 廠商收到的詢價／聯絡紀錄 |

### 4.4 數位資產（訂製／再製產出）

| 路徑 | 說明 |
|------|------|
| `/client/my-custom-products.html` | 我的數位資產：客製／再製產出的產品列表 |
| `/client/custom-product-detail.html` | 單一客製產品詳情（含引用來源、媒合廠商等） |

## 五、管理員後台

路徑皆在 **`/admin/`**，需**管理員**帳號（`profiles.role = 'admin'`）。

### 5.1 儀表板與用戶

| 路徑 | 說明 |
|------|------|
| `/admin/index.html` | 管理員儀表板 |
| `/admin/user-management.html` | 用戶管理：列表、建立帳號、編輯角色／會員等級／點數等 |

### 5.2 種子廠商管理

| 路徑 | 說明 |
|------|------|
| `/admin/seed-vendors.html` | **種子廠商管理**：代為建立廠商（綁定使用者、廠商名稱、地點、介紹、**聯繫與社群**、認證標章）、代為上傳**素材**（主分類、子分類、造型、材質、素材圖）；列表顯示剩餘天數、是否已轉付費；可一鍵**轉為付費**（將種子廠商改為一般廠商） |

- 操作手冊：`docs/種子廠商入駐操作手冊.md`
- 代建廠商帳號／密碼查詢與重設：見該手冊「如何查代建廠商的帳號（登入用）與密碼」。

### 5.3 會員、點數與金流

| 路徑 | 說明 |
|------|------|
| `/admin/membership.html` | 會員／訂閱管理：方案、點數規則、權限、用戶等級、點數流水、手動調整點數 |
| `/admin/payment-settings.html` | 金流設定（依站方整合之支付方式） |

### 5.4 分類與內容

| 路徑 | 說明 |
|------|------|
| `/admin/categories.html` | 訂製分類（custom-product-categories）管理 |
| `/admin/remake-categories.html` | 再製分類管理 |

### 5.5 網站與 AI 設定

| 路徑 | 說明 |
|------|------|
| `/admin/ga4-settings.html` | GA4 衡量 ID 設定 |
| `/admin/ai-settings.html` | AI 相關設定（模型、場景模擬／圖樣提取等系統提示詞） |
| `/admin/site-settings.html` | 網站設定（依實際功能） |

### 5.6 其他後台頁

- 分析報表、專案／提案／發票等依實際啟用項目為準（見 `public/admin/` 與側欄導覽）。

## 六、技術與 SEO 要點

### 6.1 網站地圖與 robots

- **Sitemap 索引**：`/sitemap.xml` — 列出六個子 sitemap（pages、categories、vendors、products、collections、inspiration）
- **靜態／半靜態**：`/sitemap-pages.xml`（固定清單，見 `server.js` 之 `SITEMAP_PAGES`）
- **動態**：categories（ai_categories）、vendors（manufacturers）、products（custom_products）、collections（media_collections）、inspiration（靈感牆）
- **robots.txt**：`/robots.txt` — 內含 Sitemap 網址，Disallow `/admin/`、`/api/`、`/payment/`

詳見 `docs/sitemap.md`。

### 6.2 靈感牆獨立 URL 與分享

- 格式：`/inspiration/{type}/{id}`（type：user_design、comparison、series、collection）
- 用於分享、OG 預覽、SEO；圖片可經 `/api/proxy-image` 以自家網域提供。

### 6.3 訂製產品引用來源

- 從廠商素材庫選圖後生成並儲存之訂製產品，會記錄**引用來源**（廠商、素材）；於「我的數位資產」點單筆進入詳情時，可顯示引用來源圖與廠商連結。
- 資料庫欄位：`custom_products.reference_sources`（JSONB），需執行 `docs/add-custom-products-reference-sources.sql`。

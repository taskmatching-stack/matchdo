# 參考圖四 Tab × 廠商訂製程度 — 對應表

> 兩套系統獨立：Tab 管「參考圖用途」；訂製程度管「數位原型廠商接單能力」（僅 `asset_kind=prototype`）。

## 設計頁四 Tab（參考圖）

| Tab | asset_kind | FLUX 用途 |
|-----|------------|-----------|
| 原型 | `prototype` | 造型、輪廓、比例、結構 |
| 材料 | `material` | 本體表面質感／布料色（非零件） |
| 配件 | `part` | 五金、拉鍊、掛繩等零件外觀 |
| 圖樣 | `other` | 印花、紋理、風格（不決定造型） |

送圖順序（有圖才佔號）：**原型 → 配件 → 材料 → 圖樣** → `image 1…N`。

---

## 廠商訂製程度（五 slug，僅數位原型）

| slug | 顯示 |
|------|------|
| `mono_graphic` | 單色表面圖文 |
| `color_graphic` | 彩色表面圖文 |
| `color_material` | 主體顏色／材質 |
| `size_part` | 尺寸／零件 |
| `form_structure` | 造型／結構 |

`mono_graphic` 與 `color_graphic` 廠商端互斥擇一。

---

## 對應表（訂製程度 → 建議搭配的參考 Tab）

| 訂製程度 | 主要參考 Tab | 次要／補充 |
|----------|--------------|------------|
| `form_structure` | **原型** | — |
| `size_part` | **原型**、**配件** | 此圖補充寫位置 |
| `color_material` | **材料** | — |
| `mono_graphic` | **圖樣** | 或僅文字描述 |
| `color_graphic` | **圖樣** | 或僅文字描述 |

---

## 對應表（參考 Tab → 相關訂製程度）

| 參考 Tab | 相關訂製程度 | 說明 |
|----------|--------------|------|
| **原型** | `form_structure`、`size_part` | 改形、改尺寸常看原型圖 |
| **材料** | `color_material` | 改本體面料／表面色 |
| **配件** | `size_part` | 五金、拉鍊、掛繩配置 |
| **圖樣** | `mono_graphic`、`color_graphic` | 表面印花／圖文 |

---

## 生圖時誰進 prompt

| 資料 | 進 prompt 方式 |
|------|----------------|
| 四 Tab 的圖 | `image N` 用途句（依 asset_kind） |
| 此圖補充 | 掛在對應 `image N` |
| 類別補充（Tab 底） | 併入使用者描述 |
| 訂製程度 | 僅**原型**參考且帶廠商 `customization_levels` → 製造限制附錄（未勾選項寫禁止句） |

---

## 範例：僅勾 `color_graphic` 的原型

| 項目 | 值 |
|------|-----|
| 廠商支援 | 彩色表面圖文 ✓；其餘四項 ✗ |
| 適合 Tab | **圖樣**（或文字描述彩色圖文） |
| 不暗示廠商能做 | 改造型（原型）、改材料色（材料）、大改零件（配件）— 除非另選支援那些的原型 |

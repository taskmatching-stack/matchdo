# 參考圖 Tab × 廠商訂製程度

> Tab 管「參考圖用途」；訂製程度管「數位原型廠商接單能力」（僅 `asset_kind=prototype`）。

## 設計頁參考 Tab（2026-06）

| Tab | asset_kind | FLUX 用途 |
|-----|------------|-----------|
| 原型 | `prototype` | 造型、輪廓、比例、結構 |
| 材料 | `material` | 本體表面質感／布料色（非零件） |
| 配件 | `part` | 五金、拉鍊、掛繩等零件外觀 |
| **原圖印刷** | `other` + `pattern_intent: print` | 圖稿／印花／圖案 **原樣套印**（可去背） |
| **風格參考** | `other` + `pattern_intent: style` | 表面風格參考（非逐字複製） |

送圖順序（有圖才佔號）：**原型 → 配件 → 材料 → 原圖印刷 → 風格參考** → `image 1…N`。

提示詞政策（**通用性必守**）：`docs/custom-product-reference-pattern-prompt-policy.md`

## 廠商訂製程度（五 slug，僅數位原型）

| slug | 顯示 |
|------|------|
| `mono_graphic` | 單色表面圖文 |
| `color_graphic` | 彩色表面圖文 |
| `color_material` | 主體顏色／材質 |
| `size_part` | 尺寸／零件 |
| `form_structure` | 造型／結構 |

## 以「第一張廠商數位原型」為準（UI 規則）

| 項目 | 規則 |
|------|------|
| 鎖定條件 | 原型 Tab **第一張**為素材庫數位原型（有 `vendor_asset_id`） |
| 鎖定後 | 僅能再加**同一筆** `vendor_asset_id` 的其他角度；不可混選多個原型 |
| 解除鎖定 | 清空「原型」類別 |
| 本機先上傳 | 第一張為本機圖時無訂製範圍；須清空後改從素材庫選原型 |
| **原型 Tab** | 面板內顯示五項訂製程度徽章（綠／灰） |
| **材料 Tab** 醒目 | 鎖定原型且含 `color_material` |
| **配件 Tab** 醒目 | 鎖定原型且含 `size_part` |
| **原圖印刷／風格參考 Tab** 醒目 | 鎖定原型且含 `mono_graphic` 或 `color_graphic` |
| 未醒目 Tab | 仍可上傳／選素材；不從材料／配件素材推斷訂製範圍 |
| 超出範圍提醒 | 指**廠商**在該數位原型上**未開放**的訂製項目；加入參考／開素材庫／生圖前會提醒，**不禁止**操作 |

材料、配件、原圖印刷／風格參考 Tab 的「醒目」僅為提示，**不阻擋**上傳。

## 生圖時誰進 prompt

| 資料 | 進 prompt 方式 |
|------|----------------|
| 各 Tab 的圖 | 後端 `image N` 角色句（依槽位與 `pattern_intent`） |
| 此圖補充 | 掛在對應 `image N` |
| 類別補充（Tab 底） | 併入使用者描述 |
| 訂製程度 | 鎖定之廠商原型 `customization_levels` → 製造限制附錄 |

使用者主提示詞 **可空**（有參考圖時）；勿在前端自動灌 image 對照摘要。

# 產品關聯鏈匯出 — 規劃（PDF）

> **狀態**：規劃稿，**尚未實作**（2026-06-06 起）  
> **範圍**：匯出**已設定好的**主產品關聯鏈（含圖），給廠商與訂製者下載或轉傳。  
> **格式決策**：**僅 PDF**（產品方認為 ZIP 不直觀；ZIP 不列入 Phase 1～2，若日後有「要原圖」需求再單獨評估）。  
> **不是**：重構關聯資料、不是改 guide 選取、**不是**把現有 `product-tree.html` 網頁直接列印。

---

## 一、核心要求（必守）

### 1.1 匯出檔「不要有多餘的網站介面」

匯出內容**僅能**包含與關聯鏈有關的資訊，**不得**出現：

| ❌ 不要出現 | 說明 |
|------------|------|
| 全站 header／footer、登入狀態 | `site-header` 等 |
| 「進入產品設計」「更換款式」「返回設計」 | 工作流按鈕 |
| 右側「搭配摘要」「已選參考」、選取青框 | guide 互動 UI |
| 🔍 放大、橫向箭頭、收合箭頭 | 網頁操作元件 |
| MATCHDO 導覽、步驟條 ①②③ | 站內導覽 |

**允許出現：**

- 主產品名稱（＋可選廠商名稱）
- 分區標題：`主產品 · 角粒殼3.0`、`配件 · 單色手機背帶掛繩`…
- 每張圖＋標籤（角度 N／色款名）
- 可選一頁簡短說明（如「以下為此款可搭配之材料與配件，僅供參考」）
- 產生時間、matchdo.cc 小字來源（可選，放頁尾一行即可）

**實作含意：** 不能用「在 `product-tree.html` 按列印」當正式匯出；須**獨立匯出版**（後端產 PDF，或後端產 ZIP，或極簡 `export` 專用 HTML 僅供伺服器轉 PDF）。

## 二、匯出格式：PDF（已定）

| 決策 | 說明 |
|------|------|
| **採用 PDF** | 單檔、打開即看、傳 Line／Email 直覺；版面可排成「一份可搭配目錄」 |
| **不做 ZIP（現階段）** | 多檔＋資料夾對一般使用者不直觀；除非日後明確有「必須原圖檔」需求再開議題 |

資料來源：`GET /api/vendor-assets/:id/link-tree`（與 guide 頁相同）。

## 三、匯出內容長相（示意）

### 3.1 PDF 版面（無網站 UI）

```text
┌─────────────────────────────────────────┐
│ 角粒殼3.0 · 可搭配參考                    │  ← 標題，無站內選單
│ 廠商：OOO（可選）                          │
├─────────────────────────────────────────┤
│ 主產品 · 角粒殼3.0                        │
│ [角度1圖] [角度2圖] [角度3圖] …           │
│  角度1    角度2    角度3                   │
├─────────────────────────────────────────┤
│ 配件 · 單色手機背帶掛繩                   │
│ [薰衣紫] [愛瑪橘] [甜粉] …                │
├─────────────────────────────────────────┤
│ 材料 · …（若有）                          │
├─────────────────────────────────────────┤
│ matchdo.cc · 產生於 2026-06-06（頁尾小字）│
└─────────────────────────────────────────┘
```

- 直向 A4 或類似比例；圖以 grid 排列，**全部色款／角度都列出**（不橫向捲動）  
- 不顯示「已選」「預覽中」等互動狀態

## 四、API 與入口（規劃，未實作）

| 端點 | 輸出 | 權限 |
|------|------|------|
| `GET /api/vendor-assets/:id/link-tree/export.pdf` | PDF | 公開素材 only |
| `GET /api/me/vendor-assets/:id/link-tree/export.pdf` | PDF | 廠商，可含未公開 |

- 後端：`buildPublicPrototypeLinkTree` → 極簡 HTML 模板 → **伺服器端轉 PDF**（如 puppeteer、pdfkit 等）  
- 勿依賴使用者瀏覽器對 `product-tree.html` 按列印

### 網頁上按鈕（僅觸發下載，不嵌入 PDF）

在 `product-tree.html`、`vendor-product-link-tree.html` 各加**一顆**：

- 「下載 PDF（可搭配參考）」

按鈕留在網頁上沒問題；**PDF 內**不得帶站內 UI。

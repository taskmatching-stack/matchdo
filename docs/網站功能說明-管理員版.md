前台使用者功能請見 **[網站功能說明-使用者版.md](./網站功能說明-使用者版.md)**。

**最後更新**：2026-08-07

## 一、進入方式與權限

| 項目 | 說明 |
|------|------|
| **路徑** | `/admin/` |
| **權限** | `profiles.role = admin`；`tester` 可預覽部分 AI／Playground |

## 五、統計與生圖紀錄

| 路徑 | 說明 |
|------|------|
| `/admin/platform-stats.html` | **平台統計**：分類使用、材料組合 TOP、**情境圖 vs 商攝導演**、扣點行為、表尾總計 |
| `/admin/generation-records.html` | **生圖紀錄**：主站／Embed／情境圖／商攝；詳情、**生圖履歷**、PDF、**批量 ZIP**（≤40 筆） |

### 生圖履歷（管理員）

- API：`GET /api/admin/provenance-resume`、PDF、`POST …/export.zip`
- 較使用者版多：email、`_internal`（lineage、Embed IP／session 等）
- Migration：`provenance-resume-fields`（`docs/add-provenance-resume-fields.sql`）
- 詳 `docs/PLAN-provenance-resume-export.md`、`docs/PROGRESS-provenance-resume-export.md`

## 七、SEO 與架構（管理員須知）

| 政策 | 說明 |
|------|------|
| **禁止** | 把列表／目錄做成 `custom-product.html?tab=` 充 sitemap |
| **版型列表** | `/official-templates/`、`/vendor-styles/` 為真 SSR 列表 |
| **靈感牆** | 可索引 UGC：`/inspiration/{type}/{id}` |
| **個人後台** | `/client/*` blocklist noindex |

詳 `docs/SEO-AUDIT-PLAN-2026-08-06.md`、`docs/SEO-PROGRESS.md`、`docs/architecture-and-seo-principles.md`、`.cursor/rules/seo-no-stuff-design-page.mdc`。

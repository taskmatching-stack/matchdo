### 2.1 操作介紹（前台對應）

| 前台 | 後台 |
|------|------|
| `/help/` 總目錄 | 只列出 **已發佈** 資料夾與單篇 |
| `/help/{folder}/` | 該大功能目錄 |
| `/help/{folder}/{page}` | 單篇（可 `#標題` 錨點） |
| `/help/?lang=en` | 英文欄（`title_en`、區塊 `text_en`） |

**2026-09-12 線上已發佈**：資料夾「方案與點數」三篇——訂閱方案與權益總覽、媒體牆隱私、免費帳號限制。其餘草稿樹（設計稿、商攝、製造商…）在後台改寫並勾發佈後才會出現。人像生成風格（含前台**寬鬆尺度**，內部仍為 experiment）請跑 **資料庫維護** `help-guides-promo-portrait-loose-scale-20260913`，再跑 `help-guides-promo-portrait-loose-scale-account-rate-20260913`（全站頻率與禁止裸露）。SQL：`docs/add-help-guides-promo-portrait-loose-scale-account-rate-20260913.sql`。該篇 `is_published` 才會進 `/help/` 目錄。前台與操作介紹**不寫模型名稱**。

舊靜態檔 `public/help/index.html` 不是線上 `/help/`（路由 SSR 優先）。

### 生圖履歷（管理員）

- API：`GET /api/admin/provenance-resume`、PDF、`POST …/export.zip`
- 較使用者版多：email、`_internal`（lineage、Embed IP／session 等）
- Migration：`provenance-resume-fields`（`docs/add-provenance-resume-fields.sql`）
- 詳 `docs/PLAN-provenance-resume-export.md`、`docs/PROGRESS-provenance-resume-export.md`

### 人像審核（管理員須知）

- 使用者可在帳號資訊開關「描述審核自動潤飾」；關掉仍硬擋，只是不改寫描述。
- 空白描述不做描述審核。外部圖像審核可能對同一張圖非確定性擋下。
- **不要**做 400 自動改衣著／自動重試。被擋時前台連到 `/help/promo-camera/portrait-modes`「描述審核與外部擋圖」。
- 管理員在商攝結果可對照氛圍「草稿 vs 成品」、混合「場景底圖 vs 成品」。
- 前台另有**寬鬆尺度**（與清晰同提示詞，**前台與操作介紹不寫引擎／模型名**）。給**大尺度產品**用，**仍須禁止裸露**。限**方案三／方案四**（管理員與測試員仍可用，但頻率一樣算進全站）。臉部複製較低。後台 `/admin/ai-settings.html` 可獨立設 Grok Imagine 模型 `grok_imagine_model_promo_portrait_experiment`（未存前預設 `grok-imagine-image-2.0`）、畫質（auto／low／medium）、**全站 RPM／RPS** `promo_portrait_experiment_per_minute`／`promo_portrait_experiment_per_second`（未存前對齊 Grok Tier 0：300／分、6／秒。所有帳號合計，超過排隊等待、不直接拒絕，與 Gemini 生圖佇列相同），以及 xAI API 金鑰（或 Cloud Run `XAI_API_KEY`）。不跟氛圍共用。生圖提示詞**不要**再加「不要情色感」。點數在 `/admin/membership.html` 獨立設 1 MP／4 MP，**不套訂閱 −5**。
- Gemini **生圖**另有**全站**軟上限（材料組合、印花、圖樣、材料重繪、商攝空間／人像清晰等共用，不影響標籤／翻譯）。後台同一頁「Gemini 模型設定」卡片可改每分鐘／每 10 分鐘／每天／並行／最短間隔（`gemini_image_max_per_min` 等）。未存前預設 70／分、700／10 分、每天不限、並行 8。與寬鬆尺度的 Grok RPM／RPS 是兩套。

## 七、SEO 與架構（管理員須知）

| 政策 | 說明 |
|------|------|
| **禁止** | 把列表／目錄做成 `custom-product.html?tab=` 充 sitemap |
| **版型列表** | `/official-templates/`、`/vendor-styles/` 為真 SSR 列表 |
| **操作介紹** | `/help/` 為真 SSR 目錄／單篇；不要做成設計頁 tab |
| **靈感牆** | 可索引 UGC：`/inspiration/{type}/{id}` |
| **個人後台** | `/client/*` blocklist noindex |

詳 `docs/SEO-AUDIT-PLAN-2026-08-06.md`、`docs/SEO-PROGRESS.md`、`docs/architecture-and-seo-principles.md`、`.cursor/rules/seo-no-stuff-design-page.mdc`。

Embed 對外展示：用 Google Site 嵌 iframe，不要改首頁／靈感牆當 demo。見 `.cursor/rules/embed-demo-google-site.mdc`。

# 待辦：首頁全圖牆如何插入「推廣圖」供廠商推廣

> **狀態**：待辦／規劃中 — **不實作**  
> **日期**：2026-07-19  
> **關聯**：推廣圖生成 MVP（`14f47f8`）、首頁媒體牆（`public/iStudio-1.0.0/index.html` `#media-wall-*`）  
> **硬性約束**：不破壞靈感牆篩選、卡片、lightbox 核心；可索引 UGC 仍走 `/inspiration/{type}/{id}`；`/client/*` 不上 sitemap

---

## 1. 問題意識

首頁是**全圖片密集牆**（media wall）：幾乎沒有文案區、卡片即圖。  
廠商剛有「產品推廣圖」生成能力（情境／比例／攝影參數），下一步要問：

**推廣圖生成後，要怎麼「出現在首頁這種介面」上，才算真正能幫廠商做推廣？**

重點不是再塞一個按鈕，而是：**視覺上像牆的一部分，商業上能導流到廠商／產品，SEO／權限又不踩雷。**

---

## 2. 首頁現況（決策前提）

| 項目 | 現況 |
|------|------|
| 版面 | `#media-wall-grid` 全圖 dense grid（含 1×2、對照圖特殊格） |
| 內容型態 | 使用者設計、廠商對照／系列等（靈感牆語意） |
| 互動 | 點圖 → lightbox／inspiration URL（基線勿亂改） |
| 政策 | `show_on_homepage` ≈ 上牆；sitemap 只收 `/inspiration/*` |

推廣圖若硬塞進同一套「靈感」語意，容易變成：廣告感過重、或與設計作品混在一起難篩。

---

## 3. 適合度評估：幾種插入方式

### 方案 A — 靈感牆「混排格子」（同一 grid 多一種 card type）

**做法**：media-wall API 多一種 `source_type: promo`／`vendor_promo`，視覺仍是全圖卡，可加極淡角標（如「推廣」）。

| 優 | 缺 |
|----|----|
| 最符合「全圖介面」、不另開區塊 | 易被當成靈感作品，廣告／UGC 界線模糊 |
| 實作可沿用既有 card／lightbox 骨架 | 若比例亂（9:16 vs 1:1）會打亂 dense 排版 |
| | 必須小心：勿改既有卡片點擊語意 |

**適合條件**：推廣圖**強制幾種牆用比例**（建議僅 1:1 上牆），且有明確「是否公開上首頁」開關（預設關）。

**建議角標**：極小、不蓋主體（對齊對照圖用邊框區隔的精神，勿飄浮 badge 滿版）。

---

### 方案 B — 牆內「廠商推廣帶」固定插槽（推薦優先評估）

**做法**：在 dense grid 裡保留少數**固定位置插槽**（類似現有 comparison／1×2 定位邏輯），專門放「本週／付費曝光」推廣圖；其餘格仍是靈感內容。

| 優 | 缺 |
|----|----|
| 全圖語彙不變，但**商業區與靈感區可分離** | 需設計插槽規則（每 N 列 1 格、左右交替等） |
| 廠商付費／點數換曝光有清楚商品 | 插槽過多會「廣告化」傷害首頁質感 |
| 不強迫每張推廣圖都進無限混排 | 要防同一廠商佔滿插槽 |

**適合條件**：推廣＝**曝光商品**，不是每張生成圖自動上牆。

**建議上限（待定）**：例如首屏最多 1～2 個推廣插槽；無限捲動每 12～18 格最多 1 個。

---

### 方案 C — 首頁上方獨立「推廣橫幅列」（非混入牆）

**做法**：media-wall **上方**一條橫向全圖 strip（或 3～5 張橫滑），與靈感牆分開。

| 優 | 缺 |
|----|----|
| 完全不碰牆核心邏輯（最安全） | 比較不像「牆的一部分」，偏傳統廣告列 |
| 比例可用 16:9／橫幅 | 手機首屏變長，可能擠掉靈感 |

**適合**：要**最快上線、零風險動牆**時的過渡方案；長期可與 B 並存或被 B 取代。

---

### 方案 D — 不上首頁牆，改「廠商公開頁／嵌入」為主戰場

**做法**：推廣圖主要出現在：

- 廠商公開頁素材區／作品區  
- embed 卡片牆／活動 Landing  
- 下載後廠商自行發社群  

首頁只放「精選」或完全不放。

| 優 | 缺 |
|----|----|
| 符合「推廣圖＝行銷素材」本質 | 首頁曝光弱，廠商可能覺得功能沒閉環 |
| SEO／靈感牆零污染 | 需另做公開頁展示位 |

**建議**：與 A/B **並存**——生成後預設下載＋可勾「申請上首頁曝光」（審核或付費），不是自動全上。

---

### 方案 E — Lightbox／詳情內「相關推廣」（點進靈感後再推）

**做法**：牆卡仍是靈感；點開後在側欄或下方顯示「同分類廠商推廣圖」。

| 優 | 缺 |
|----|----|
| 不破壞首屏全圖節奏 | 曝光較軟、轉換路徑長 |
| | 仍要處理「誰的推廣、會不會吵」 |

可當 **Phase 2 加值**，不宜當唯一推廣出口。

---

## 4. 建議方向（待決策，非正式定案）

**較合首頁全圖介面、又比較能幫廠商推廣的組合：**

1. **主路徑（曝光）**：方案 **B 牆內推廣插槽** + 嚴格密度上限  
2. **素材路徑（自用）**：方案 **D** 下載／公開頁／社群（生成功能本來就要服務這個）  
3. **過渡／低風險**：必要時先上方案 **C** 橫幅列，驗證點擊與投訴率  
4. **慎用**：方案 **A 無限混排** — 除非有「上牆審核／付費／比例白名單」

一句話：  
**推廣圖要「像牆上一格圖」，但不要「假裝成靈感作品」；用插槽或獨立帶標示商業意圖，比全部混進靈感流更適合。**

# MatchDO 合做 — 網站完整功能說明

本文件為 **MatchDO 全站功能總覽**，供產品、營運、開發與對外說明使用。  
**操作步驟**請見 `docs/user-manual.md`；**帳號與選單規範**請見 `docs/account-one-login-capabilities.md`。  
**衍生 Side Project**（如攝影模擬 App）見 **§十三**，與主站功能分開說明。

**最後更新**：2026-08-02

---

## 一、網站定位

**MatchDO 合做**是「數位合作市集」：連結 **訂製者（設計／發想）**、**製造商（接單／展示／數位版型）** 與 **產業供應商（上游目錄）**，以 AI 輔助設計、素材管理與行銷影像產出。

核心價值：

| 面向 | 說明 |
|------|------|
| **訂製設計** | 選分類、寫描述、引用廠商版型／材料，生成設計稿 |
| **廠商展示** | 公開首頁展示作品集與素材庫，供訂製者引用 |
| **上游採購（B 線）** | 製造商瀏覽產業供應商目錄，匯入原型組／材料至自己的素材庫 |
| **行銷影像** | 攝影模擬／情境圖生成，供社群、廣告、媒體牆使用 |
| **點數經濟** | 上傳、AI 生圖、重繪、放大、情境合成等依方案扣點 |

### 1.1 產品邊界：主站 vs 衍生 Side Project

| | **MatchDO 主站** | **衍生 Side Project** |
|---|------------------|-------------------------|
| **定位** | 數位合作市集（訂製、廠商、供應商、素材、B 線） | 自主站**長出來**的獨立產品線，可單獨發行 |
| **現有範例** | 產品設計、素材庫、產業目錄、媒體牆… | **攝影模擬 App**（PWA／Store） |
| **帳號** | 同一 MatchDO 登入 | **共用帳號與點數**（非另一套會員） |
| **後端** | `server.js` 各 API | 仍打主站 `/api/promo-camera/*`，**不另開生圖服務** |
| **程式** | `public/` 全站 | App 殼：`/promo-camera-app`；Store：`apps/matchdo-promo-camera/`（與 Cloud Run 部署**分離**） |
| **整站 App** | 僅 Web | **無**整站原生 App 規劃 |

> **攝影模擬**在主站是「行銷影像」功能的一環（§5.2）；**攝影模擬 App** 則是同一能力的手機／Store 發行形態，詳 **§十三**。

## 二、帳號模型（必讀）

### 2.1 同一登入，沒有「角色切換」

| 原則 | 說明 |
|------|------|
| **一個 Email 帳號** | 不區分「訂製者帳號／製造商帳號／供應商帳號」 |
| **①②③ 只是選單分區** | 登入後「我的功能」固定分三區，**全部連結常駐顯示** |
| **頁內才做限制** | 資格不足時在 **頁面或 API** 提示／403，**不從選單隱藏入口** |

詳見 `docs/account-one-login-capabilities.md`。

### 2.2 全站僅兩項業務限制

| 限制 | 對象 | 條件 |
|------|------|------|
| **A. 不可上傳產品與素材** | 免費會員（無有效付費訂閱） | 不可上傳 `vendor_assets`（數位版型）與 `supplier_catalog_items`（供應商目錄品項）；**展示案例**上傳不在此限 |
| **B. 不可匯入供應商目錄** | 製造商 | 須至少 **1 件公開展示中** 的 `manufacturer_portfolio`；管理員／測試員除外 |

API 欄位：`GET /api/me/capabilities` → `can_upload_products_and_assets`、`can_import_supplier_catalog`。

### 2.3 選單結構（`public/js/site-header.js`）

**頂部導覽**

| 區塊 | 內容 |
|------|------|
| **客製產品** | 產品設計、圖庫找廠商、行銷影像、我的數位資產 |
| **設計風向** | 設計風向首頁、設計意圖分析、我的設計風向、找製造商、圖庫 |
| **方案與定價** | 訂閱方案 |
| **我的功能** | 見下方 ①②③ |

**我的功能（登入後）**

| 分區 | 主要入口 |
|------|----------|
| **① 訂製／設計** | 控制台、我的數位資產、對話、我的點數、我的 AI 編輯區 |
| **② 製造商** | 廠商控制台、廠商公開首頁、展示案例、數位版型；**上游採購（B 線）**：產業供應商目錄、已匯入上游品項；訂製需求、聯絡方式 |
| **③ 產業供應商** | 上架數位產品庫、製造商引用紀錄、供應商公開首頁 |

**頭像選單（全站）**：帳號資訊、我的點數、**攝影模擬**（`/promo-camera`）、聯絡設定；管理員另有後台入口。

## 三、兩條資料線（A 線／B 線）

| | **A 線・訂製者設計參考** | **B 線・製造商採購參考** |
|---|--------------------------|---------------------------|
| **資料表** | `vendor_assets` | `supplier_catalog_items` + 匯入紀錄 |
| **誰維護** | 製造商、官方版型池 | 產業供應商、管理員代上架 |
| **誰使用** | **訂製者**（產品設計頁） | **製造商**（須有展示案例才可匯入） |
| **入口** | `/custom-product.html`、廠商公開頁「用此廠商版型設計」 | `/client/industry-suppliers.html`、已匯入紀錄 |
| **語意** | 設計頁可引用、記錄 `reference_sources` | 匯入後複製至 `vendor_assets`，**不進**訂製者設計頁 |

詳見 `docs/三角色架構與AB線說明.md`、`docs/architecture-and-seo-principles.md`。

## 五、① 訂製／設計功能

需登入。以下為訂製者與一般使用者主要工作流。

### 5.1 產品設計（核心）

**路徑**：`/custom-product.html`

| 分頁／功能 | 說明 |
|------------|------|
| **產品設計** | 選訂製分類、輸入描述、上傳或引用參考圖（最多 8 張）；可混用**數位原型**與**材料**；生成設計稿；儲存至數位資產、找廠商訂製 |
| **廠商版型** | 瀏覽各廠商上傳的數位原型，一鍵帶入設計 |
| **官方版型** | 瀏覽平台官方版型池（與廠商素材分開 API） |
| **實境模擬** | `?tab=scene-sim` — 環境／人物圖 + 產品圖合成情境（扣點） |
| **圖樣提取** | `?tab=pattern-extract` — 上傳圖片提取圖樣，可無縫拼接（依解析度扣點） |
| **行銷影像** | `?tab=promo-image` — 入口至情境圖／攝影模擬工作流 |

**引用廠商素材**：從素材庫選圖後，儲存時記錄 `reference_sources`（廠商、素材 ID），詳情頁可查看來源。

**產品描述**：要在產品上出現的文字，請用半形雙引號 `" "` 包住；引號內印刷文字送生圖時不翻譯。

### 5.2 攝影模擬／情境圖（行銷影像）

| 路徑 | 說明 |
|------|------|
| `/promo-camera` | **網站獨立頁**：含原站 header；可 `?back=design`／`?back=vendor` 控制返回 |
| `/custom-product.html?tab=promo-image` | 設計頁「行銷影像」入口 |
| `/custom-product.html?tab=promo-camera` | 設計頁內 **iframe 嵌入**（`?embed=design`，noindex） |

生成紀錄存於 **`product_promo_generations`**，在「我的數位資產 → 情境圖」管理；可勾選「展示在媒體牆」。

**人物／動物選項**（攝影模擬）：

| 選項 | 用途 |
|------|------|
| **保留** | 源圖有人物／動物時盡量保留；細節可依描述調整 |
| **不含** | 移除人物／動物，只留產品與環境 |
| **依提示詞** | 不複製源圖人物；描述有寫才依文字創作新人／動物 |

### 5.3 攝影模擬 App（Side Project 摘要）

**攝影模擬 App** 是 MatchDO 主站**衍生**的 Side Project，不是整站 App，也不代表 MatchDO 全功能行動化。

| 項目 | 說明 |
|------|------|
| **與主站關係** | 能力來自主站「攝影模擬／情境圖」；共用帳號、點數、生圖 API、數位資產 |
| **獨立之處** | 專用手機 UI（`/promo-camera-app`）、PWA manifest、Capacitor Store 子專案；**不含**產品設計、素材庫、B 線等 |
| **完整說明** | 見 **§十三、衍生 Side Project：攝影模擬 App** |

### 5.4 我的數位資產

**路徑**：`/client/my-custom-products.html`

| 分頁 | 內容 |
|------|------|
| **設計稿** | 客製產品 AI 協作稿（非定案圖面） |
| **情境圖** | 攝影模擬／行銷影像產出（`?tab=promo` 可直接開啟） |
| **設計風向** | 設計意圖分析產出（`?view=design-direction`） |

**詳情**：`/client/custom-product-detail.html?id=` — 含引用來源、媒合資訊等（**noindex**，canonical 指向 inspiration URL）。

### 5.5 AI 編輯區

**路徑**：`/client/ai-edit.html`（選單「我的 AI 編輯區」）

統一入口：高解析度 **AI 放大**、後續擴充 Edit／Control 等子功能。素材庫內小圖（&lt;0.5 MP）可就地預覽放大；大圖請至此區操作。

## 六、② 製造商功能

需登入；多數功能須先**建立廠商資料**（`manufacturers`）。

### 6.1 公開頁 vs 後台

```
訪客看到的「廠商首頁」              廠商本人登入的「後台」
/vendor-profile.html?id=UUID  ←→  /client/manufacturer-dashboard.html
     │ 作品集、素材庫、聯絡              │ 上傳、排序、複製網址
     ↑ 內容來自下列兩頁 ─────────────────┘
/client/manufacturer-portfolio.html   → 展示案例（系列／對照圖）
/client/manufacturer-materials.html   → 數位版型（素材庫）
```

| 路徑 | 說明 |
|------|------|
| `/vendor-profile.html?id=…` | **對外主頁**（可索引） |
| `/client/manufacturer-dashboard.html` | **後台總覽** |
| `/profile/contact-info.html` | 聯絡資訊、廠商名稱／簡介（顯示於公開頁） |

### 6.2 展示案例（作品集）

**路徑**：`/client/manufacturer-portfolio.html`

| 類型 | 說明 |
|------|------|
| **系列圖** | 同一作品多張圖 |
| **對照圖** | 設計稿 + 完成品／實品對照 |

出現在公開頁「作品集」與靈感牆。**至少 1 件公開展示案例**方可解鎖 B 線匯入（限制 B）。

### 6.3 數位版型（素材庫）

**路徑**：`/client/manufacturer-materials.html`  
**官方版型庫（管理員）**：同頁 `?official_platform=1&manage=1`

分三類上傳：

| 類型 | 說明 | 圖片 |
|------|------|------|
| **數位原型** | 主產品版型，供訂製者引用 | 封面 + 多角度（最多 12 張）；可設連動組（同色同款） |
| **配件／零件** | 配件參考 | 同上 |
| **材料／顏色** | 材質色卡、樣張 | 封面（多色滿版色卡，**僅展示**）+ 單色樣張（設計者可選，最多 48 張） |

**材料特別規則**：

- **封面**（第一張）：AI 只讀封面產生標籤／說明；**設計者不可選**（`designer_selectable: false`）
- **其餘單色樣張**：供設計者在產品設計頁選用
- **列表縮圖**：1:1 方形、`object-fit: contain`（不裁切）
- **AI 重繪**：材料走 img2img 1024×1024 優化（依「材質類型」欄位，非查表硬編碼）

**附帶能力**（原型／配件／材料共用待傳 UI）：

- 逐張 **AI 重繪**、**AI 放大**（材料放大請至 AI 編輯區）
- 編輯時可新增角度圖、拖曳排序、設封面
- **產品推廣圖**分頁：選產品卡生成情境主視覺（與上傳流程分開）

**種子廠商**（`vendor_source = seed`）：平台代管，廠商本人僅可查看，不可編輯；詳 `docs/種子廠商入駐操作手冊.md`。

### 6.4 上游採購（B 線）

| 路徑 | 說明 |
|------|------|
| `/client/industry-suppliers.html` | 瀏覽產業供應商與其數位產品庫 |

| `/client/my-supplier-references.html` | 已匯入上游品項管理 |

## 九、點數與 AI 能力總覽

點數用於上傳、生圖、重繪、放大、情境合成等；規則見 `/admin/membership.html` 與 `payment_config`。

| 功能 | 典型扣點對象 | 備註 |
|------|--------------|------|
| 素材上傳 | 製造商／供應商 | 基礎上傳費；含 AI 標籤／說明 |
| 產品設計生圖 | 訂製者 | FLUX；依解析度 |
| 實境模擬 | 訂製者 | 環境 + 產品合成 |
| 圖樣提取 | 訂製者 | 依輸出 MP |
| 攝影模擬／情境圖 | 訂製者／製造商 | 基礎 1MP 起跳；獨立 FLUX 槽 |
| 素材 AI 重繪 | 製造商／供應商 | 原型／材料 img2img |
| AI 放大 | 訂製者 | AI 編輯區；素材庫小圖可預覽 |

**失敗不扣點**為多數 AI 功能的預設政策（依各 API 實作為準）。

**提示詞政策**：材料／生圖禁止查表式硬編碼；以 Gemini 視覺語意 + 分類 DB prompt 為準。見 `docs/flux-and-gemini-prompt-policy.md`。

## 十三、衍生 Side Project：攝影模擬 App

**攝影模擬 App** 是 MatchDO 主站**衍生的 Side Project**：把主站「行銷影像／情境圖」能力，做成可**獨立發行**的手機 App 形態（PWA 或 Store），**不是** MatchDO 整站 App，也不涵蓋產品設計、素材庫、B 線等主站功能。

### 13.1 為何是 Side Project

| 面向 | 說明 |
|------|------|
| **起源** | 主站已有 `/promo-camera` 攝影模擬；App 為同一能力的**行動版殼** |
| **產品身份** | 可單獨「加到主畫面」或上架 Store，UI 專為手機單手操作 |
| **技術共用** | 帳號、點數、`/api/promo-camera/*`、數位資產「情境圖」皆與主站同一套 |
| **部署分離** | Capacitor 子專案 `apps/matchdo-promo-camera/` 與 Cloud Run 主站部署**分開** |

### 13.2 入口與型態

| 型態 | 入口 | 說明 | 狀態 |
|------|------|------|------|
| **PWA（Web App）** | `/promo-camera-app` | 無原站 header/footer 的 **App 殼 UI**；可「加到主畫面」；`promo-camera-app.webmanifest` | ✅ 已上線 |
| **舊路徑轉址** | `/client/promo-camera-app.html` | 301 → `/promo-camera-app` | ✅ |
| **Capacitor Store 版** | `apps/matchdo-promo-camera/` | Android／iOS 殼；`www/` 由 `promo-camera-app.html` sync；API 仍打 `matchdo.cc` | ⏳ 本機 Android 可跑；**商店上架／IAP 待做** |
| **整站 App** | — | 客製、素材庫、B 線等 **僅 Web** | ❌ 無規劃 |

### 13.3 與主站 `/promo-camera` 的差異

| 項目 | `/promo-camera`（主站） | `/promo-camera-app`（Side Project） |
|------|-------------------------|-------------------------------------|
| 定位 | 主站「行銷影像」功能之一 | 衍生 App，可獨立安裝 |
| 導覽 | 有原站 header、返回連結 | 全螢幕 App UI（`pc-app-shell`） |
| 設定版面 | 桌面／平板友善 | **手機單手操作**（情境／輸出收納區等） |
| 安裝 | 瀏覽器書籤 | 瀏覽器「加到主畫面」或 Store 安裝 |
| 登入／儲值 | 站內同域 | Store 版登入／儲值連結導回 `matchdo.cc` |

**生圖紀錄**：不論主站 Web、PWA 或 Store，結果皆進同一帳號的「我的數位資產 → 情境圖」；DB 可選記 `client_channel`（`web`／`app`／`embed`）。


## 一、四階：數據可見度 × AI 顧問權限

方案對照：`免費會員` / `方案二 $300` / `方案三 $900` / `方案四 $1,800`（見 `seed-subscription-plans.sql`）。

### 🆓 免費會員／訪客 — The Teaser（眼饞誘餌）

| 維度 | 規格 |
|------|------|
| **可見數據** | 僅首頁媒體牆各大分類 **Top 3 熱門風格／標籤** 字眼（無次數、無 %） |
| **AI 顧問** | ❌ 無 |
| **UI 引導** | 在**其作品旁**（或作品卡）灰色按鈕：**「🪄 讓 AI 診斷我的設計是否會紅？」** → 點擊彈窗：「請升級基礎廠商 ($300) 並使用點數，解鎖專屬商業顧問。」 |
| **商業目的** | 眼饞 + 導向 $300 |

### 🥉 $300 基礎廠商 — Tactical Advisor（短期微調與跟風）

| 維度 | 規格 |
|------|------|
| **可見數據** | Top 10 排行榜、近期 Tags **短期成長率**（7 天／30 天斷代，無長歷史） |
| **AI 顧問** | ✅ 每次 **扣 10 點** |
| **餵給 Gemini** | 僅 **過去 7 天標籤排名**（來自 `daily_trend_stats` 或等價聚合） |
| **報告風格** | 短期戰術（範例見下） |
| **Upsell 心機** | 報告結尾固定備註：無法分析下月衰退風險 → 升級 $900 Pro 生命週期預測 |

**報告範例（$300）**：

```text
🤖 MatchDO AI 診斷結果 (消耗 10 點)：
「老闆您好！您的這款『黑色尼龍後背包』符合本週熱門排名第 4 的 #極簡黑。
⚠️ 短期警告： 本週 #YKK防水拉鍊 的需求激增 120%，您的產品目前缺少此特徵。
💡 建議： 建議您立即微調此產品，加入防水拉鍊標籤，能快速蹭上本週的流量熱度！」
※ 備註：因權限限制，無法為您分析該風格下個月的衰退風險，建議升級 $900 Pro 版獲取生命週期預測。
```

## 四、現行「設計風向」對照 — 是否需要調整？

### 4.1 目前已上線（2026-05-21 後）

| 項目 | 現況 | 與新規劃差距 |
|------|------|------------|
| `/remake/` | 介紹 + 連到意圖分析／我的設計風向 | 未提 AI 顧問、未提市場 Top3 |
| `/remake-product.html` | **生圖表單**（再製分類 + 必傳參考圖） | 非「結構化意圖分析報告」；無顧問按鈕 |
| 我的設計風向 | 列表 UI（`?view=design-direction`），**未篩選** product_line | **缺** 🪄 診斷按鈕（免費灰／付費） |
| 儲存 | `custom_products`，無 `product_line` | 顧問難區分客製 vs 風向作品 |
| 語意標籤 | 生圖後 `enrichCustomProductSemantics` | ✅ 可作顧問輸入與市場 tag 比對 |
| 材料回推需求 | `reference_sources` 有，分析未 JOIN 素材 | ❌ 顧問／意圖分析應能從材料推導需求；見 **`docs/design-analysis-material-backtrace.md`** |
| 首頁媒體牆 | 50/30/20 混排 | **未**依分類顯示 Top3 標籤誘餌 |
| 點數 | 生圖等有規則 | **無**「AI 顧問 10 點」規則 |
| 會員 gate | 部分功能有訂閱檢查 | **無** tier 分級餵料 |

### 4.2 建議調整（規劃層，待開發時做）

#### A. 產品線／資料（優先，D 系列）

1. **`product_line`**：`custom` | `design_direction`；儲存時從 `remake-product` 寫入 `design_direction`（或 `remake` 遷移）。  
   → **我的設計風向** 才能只列風向作品；顧問預設只診斷風向列。

2. **儲存 payload** 增加 `analysis_source: 'design_direction'` 或 `categorySource` 快照進 `analysis_json`，供顧問還原脈絡。

3. **D4 拆分目標**（更新 D 系列定義）：  
   - **D4a**：意圖分析 UI（可先保留生圖，加「分析摘要」區塊占位）  
   - **D4b**：不阻塞 AD，顧問按鈕放列表/詳情

#### B. 文案與導覽（短期可做，低風險）

| 位置 | 建議 |
|------|------|
| `/remake/` 首頁 | 加一句：「升級廠商方案可解鎖 **AI 產品顧問**（籌備中）」；勿承諾已上線 |
| 我的設計風向 | 卡片預留 **顧問按鈕區**（disabled + tooltip「即將推出」）— 可選 |
| 選單 | **暫不**加「風向趨勢」「AI 顧問」死連結；等 DS-4 / AD-4 |

#### C. 與客製產品區隔

| 客製產品 | 設計風向 |
|----------|----------|
| 從零設計、訂製分類 | 參考圖 + 風向分類 + **市場對標**（顧問） |
| 我的數位資產 | 我的設計風向 |
| 顧問（規劃） | 可選開放給客製作品，但餵料 tier 相同；或僅風向作品可診斷 — **待 AD-0 拍板** |

#### D. 首頁免費 Top 3

- 屬 **DS + 此規劃免費層**，非 `remake-product` 本體。  
- 實作於首頁或 `/design-signals/` 公開區，與媒體牆並列或疊加。

#### E. 後台

- **設計風向分類** prompt 改「意圖／風格」語意（D2）— 與顧問報告用語一致。  
- 點數後台新增「AI 設計顧問」項目（AD-1）。

### 4.3 不必急著改（維持現狀即可）

- URL `/remake/`、`remake_categories` 表名（內部可保留）。  
- 生圖流程可保留至 D4a 有獨立分析 API 再收斂。  
- 與 **Design Signals 付費報表頁** 分開上線，不綁在一次 deploy。

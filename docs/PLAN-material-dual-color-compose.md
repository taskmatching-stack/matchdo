# 材料雙色卡（Step1 色卡 + Step2 FLUX 材質）

## 流程

### Step 1 — 純前端 canvas（不扣點）

- 1024×1024，上方 **2/3 主色**、下方 **1/3 配色**
- 兩個 HEX 輸入即可
- 輸出：**PNG** 雙色色卡（避免 JPEG 模糊分界；無縫線、無灰底、無第三色）

### Step 2 — 對齊 BFL 官網 playground（成功後扣點）

#### 官網有印花成功案例（2026-08-05 實測）

| 項目 | 值 |
|------|-----|
| Model | FLUX.2 [pro] |
| Prompt | `依原圖上方色塊改為印花尼龍布材質，下方色塊改為皮革材質，解析度1024x1024，請維持原圖色塊比例` |
| 參考圖 | ① 色卡（2/3·1/3）② 印花圖樣 |
| Seed | `3647440197` |
| Safety | `2` |
| Prompt upsampling | **true** |
| 輸出 | 1024×1024 |

#### 本站對應

| 條件 | 管線 |
|------|------|
| **無印花** | 色卡一次 img2img；結尾「不需要文字」；**`disable_pup`**（無印花時關 PUP 才穩比例） |
| **有印花** | 色卡 + **一張**印花參考；該區材質前加「印花」；結尾「請維持原圖色塊比例」；**`prompt_upsampling: true`** |

**規則：** 印花只能用於主色區 **或** 配色區擇一，禁止兩區同時傳圖。

**禁止再犯：**

- ❌ 自創「圖2印花圖樣的…」長句偏離官網
- ❌ 有印花時分區硬拼（偏離官網單次請求）
- ❌ 有印花時關 PUP（與官網成功設定相反）
- ❌ 上下兩區同時附印花參考圖
- ❌ 英文翻譯／攝影參數

## FLUX prompt 模板

無印花：

```
依原圖上方色塊改為{主}材質，下方色塊改為{配}材質，解析度1024x1024，不需要文字
```

主色區有印花（對齊官網）：

```
依原圖上方色塊改為印花{主}材質，下方色塊改為{配}材質，解析度1024x1024，請維持原圖色塊比例
```

參考圖順序：圖1＝色卡，其後依序為主色區印花、配色區印花（有選才附）。

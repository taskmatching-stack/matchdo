# 材料雙色卡（Step1 色卡 + Step2 FLUX 材質）

## 流程

### Step 1 — 純前端 canvas（不扣點）

- 1024×1024，上方 **75% 主色**、下方 **25% 配色**
- 兩個 HEX 輸入即可
- 輸出：**PNG** 雙色色卡（避免 JPEG 模糊分界；無縫線、無灰底、無第三色）

### Step 2 — 對齊 BFL 官網 playground（成功後扣點）

#### 官網有印花成功案例（2026-08-05 實測）

| 項目 | 值 |
|------|-----|
| Model | FLUX.2 [pro] |
| Prompt | `依原圖上方色塊改為印花尼龍布材質，下方色塊改為皮革材質，解析度1024x1024，請維持原圖色塊比例` |
| 參考圖 | ① 色卡（現為 75%·25%）② 印花圖樣 |
| Seed | `3647440197` |
| Safety | `2` |
| Prompt upsampling | **true** |
| 輸出 | 1024×1024 |

#### 本站對應

| 條件 | 管線 |
|------|------|
| **無印花** | 色卡一次 img2img；結尾「請維持原圖色塊比例」；**`disable_pup`** |
| **有印花** | 色卡 + **一張**印花參考；使用者選 **印花圖樣** 或 **印花色**；**`prompt_upsampling: true`** |

**規則：** 印花只能用於主色區 **或** 配色區擇一，禁止兩區同時傳圖。用法由使用者 radio 選擇（`print_kind`），不自動判斷。

| 使用者選 | `print_kind` | Prompt 用詞 | 語意 |
|----------|--------------|-------------|------|
| **印花圖樣**（預設） | `pattern` | `上方／下方印花圖樣{材質}材質` | 圖給結構；色跟色卡 HEX |
| **印花色** | `color` | `上方／下方印花色{材質}材質` | 色跟印花圖 |

**禁止再犯：**

- ❌ 加「不需要文字／禁止改成各半／不要…」等**反向詞**（FLUX 不擅長，易漂成 50／50）
- ❌ 自創「保持原色／圖2…」長句
- ❌ 為保色去改印花區色卡為灰／白
- ❌ 有印花時分區硬拼
- ❌ 有印花時關 PUP（與官網成功設定相反）
- ❌ 上下兩區同時附印花參考圖
- ❌ 英文翻譯／攝影參數
- ❌ AI／後端依圖檔自動切 印花色／印花圖樣

**比例：** 靠色卡原圖 + 正向句「請維持原圖色塊比例」；無印花時再關 PUP。勿用反向句硬擋 1/2。

## FLUX prompt 模板

無印花：

```
依原圖上方色塊改為{主}材質，下方色塊改為{配}材質，解析度1024x1024，請維持原圖色塊比例
```

主色區＋印花圖樣：

```
依原圖上方色塊改為上方印花圖樣尼龍布材質，下方色塊改為壓紋皮革材質，解析度1024x1024，請維持原圖色塊比例
```

主色區＋印花色：

```
依原圖上方色塊改為上方印花色尼龍布材質，下方色塊改為壓紋皮革材質，解析度1024x1024，請維持原圖色塊比例
```

印花參考與色卡一律經全站 **`resolveImageToBase64`** 再送 BFL。單次生成，不硬拼。

# 材料雙色卡（Step1 色卡 + Step2 FLUX 材質）

## 流程

### Step 1 — 純前端 canvas（不扣點）

- 1024×1024，上方 **75% 主色**、下方 **25% 配色**
- 兩個 HEX 輸入即可
- 輸出：**PNG** 雙色色卡（避免 JPEG 模糊分界；無縫線、無灰底、無第三色）
- 比例標註只放在**選色**區；材質欄勿再寫 75%／25%（無意義）

### Step 2 — 單次 FLUX img2img（成功後扣點）

| 條件 | 管線 |
|------|------|
| **無印花** | 色卡一次 img2img；**`disable_pup`** |
| **有印花** | 色卡 + **一張**印花參考；使用者選 **印花圖樣** 或 **印花色**；**`prompt_upsampling: true`** |

**規則：** 印花只能用於主色區 **或** 配色區擇一。用法由使用者 radio 選擇（`print_kind`），**不**自動判斷。

色卡與印花一律經全站 **`resolveImageToBase64`** 再送 BFL（色卡**有**當 `input_image`；比例漂是模型重排，不是沒傳圖）。

## 三種模式（2026-08-05 使用者實測）

| 模式 | `print_kind` | Prompt 用詞 | 實測行為（先維持現況） |
|------|--------------|-------------|------------------------|
| **無印花** | — | `{主}材質`／`{配}材質` | 色跟色卡 HEX；比例靠色卡＋句內「75%／25%」 |
| **印花圖樣**（預設） | `pattern` | `上方／下方印花圖樣{材質}材質` | **較能保留印花圖上的配色（圖樣原色）** |
| **印花色** | `color` | `上方／下方印花色{材質}材質` | 較不保留印花原色（色易跟色卡／材質化改寫） |

> **注意：** 用詞「印花色／印花圖樣」與最初產品語意不完全對齊；實測以表為準。使用者決定先不改 code，只記文件。

若要印花圖自己的顏色 → 選 **印花圖樣**。

## FLUX prompt 模板（三種同一骨架）

無印花：

```
依原圖上方色塊75%改為{主}材質，下方色塊25%改為{配}材質，解析度1024x1024，請維持原圖色塊比例
```

主色區＋印花圖樣：

```
依原圖上方色塊75%改為上方印花圖樣{主}材質，下方色塊25%改為{配}材質，解析度1024x1024，請維持原圖色塊比例
```

主色區＋印花色：

```
依原圖上方色塊75%改為上方印花色{主}材質，下方色塊25%改為{配}材質，解析度1024x1024，請維持原圖色塊比例
```

（配色區有印花時：`下方印花圖樣…`／`下方印花色…`，對稱。）

共同參數：seed `3647440197`、safety `2`、1024×1024、中文直送（`skipPromptTranslation`）。

## 比例

- 色卡 canvas：**75%／25%**（比舊 2/3·1/3 更懸殊，方便對照結果）
- Prompt 正向寫明「上方色塊75%、下方色塊25%」＋「請維持原圖色塊比例」
- **勿**加「不需要文字／禁止各半／不要…」等反向詞（FLUX 不擅長，易漂 50／50）
- 單靠短句仍可能被模型重排；無印花時關 PUP。目前不硬拼分區。

## UI（精簡）

- 有印花才顯示兩個 radio：**印花圖樣**｜**印花色**
- **不要**在頁面顯示「材質描述／實際送出」整段 prompt（廢話）
- 印花選擇視窗：標準 Bootstrap `modal-lg`（對齊其他數位資產選擇，勿自訂 fixed 縮窗）

頁面 build 字串：`window.__MATCHDO_DUAL_COLOR_BUILD`（部署後對照）

## 禁止再犯

- ❌ 反向詞擋比例
- ❌ 為「保色」改印花區色卡成灰／白
- ❌ 有印花時分區硬拼（未另開需求前）
- ❌ 有印花時關 PUP（與有印花官網設定相反）
- ❌ 上下兩區同時附印花
- ❌ 英文翻譯／攝影參數
- ❌ AI／後端自動切 印花色／印花圖樣
- ❌ 為 Store／其他需求改共用材料上傳管線時順便動本頁未要求項

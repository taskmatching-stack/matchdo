## 一、網站定位

**MatchDO 合做**是「數位合作市集」：連結 **訂製者（設計／發想）**、**製造商（接單／展示／數位版型）** 與 **產業供應商（上游目錄）**，以 AI 輔助設計、素材管理與行銷影像產出。

| 面向 | 說明 |
|------|------|
| **訂製設計** | 選分類、寫描述、引用廠商版型／材料，生成設計稿 |
| **廠商展示** | 公開首頁展示作品集與素材庫，供訂製者引用 |
| **上游採購（B 線）** | 製造商瀏覽產業供應商目錄，匯入原型組／材料至自己的素材庫 |
| **行銷影像** | 情境圖、商攝導演，供社群、廣告、媒體牆使用 |
| **點數經濟** | 上傳、AI 生圖、重繪、放大、情境合成等依方案扣點 |

### 1.1 主站 vs 商攝 App（Store 發行）

| | **MatchDO 主站** | **商攝導演 App**（獨立發行） |
|---|------------------|------------------------------|
| **定位** | 數位合作市集全功能 | **行銷影像**拆成可上架的獨立 App（iOS／Android Store） |
| **帳號** | MatchDO 登入 | **共用**帳號與點數 |
| **商攝入口** | `/promo-camera`（官網工具，**凍結**不為 Store 改壞） | `/promo-camera-app`（PWA）→ `apps/matchdo-promo-camera/`（Capacitor **Store 包**） |
| **設計頁嵌入** | `/promo-camera?embed=design` | 手機 embed 改載 App 殼（見隔離層文件） |

**產品策略**：商攝能力留在主站供既有使用者；**對外 Store 上架以獨立 App 品牌／包名**交付，不把所有主站功能塞進 App。主站 `/promo-camera` 與 Store 實驗目錄 **隔離開發**（`.cursor/rules/promo-camera-app-isolation.mdc`）。

詳 **§十二**、`docs/PROGRESS-promo-camera-app-store.md`。

## 五、① 訂製／設計

需登入。

### 5.1 設計稿（產品設計工作區）

**路徑**：`/custom-product.html`（頂部選單：**設計稿**）

選分類、描述、參考圖（最多 8 張，可混原型＋材料）；右側資產庫可選材料組合、印花；生成後存至數位資產。  
從 [廠商版型](/vendor-styles/)、[官方版型](/official-templates/) 列表「用此款設計」會 **深鏈進此頁**（帶版型 id），不在設計頁內做總目錄。

**提示**：產品上要出現的文字請用半形雙引號 `" "` 包住。

### 5.2 情境圖與商攝導演

| 路徑 | 說明 |
|------|------|
| `/promo-image/` | **情境圖**：主題／場景 + 產品圖，偏社群／廣告情境合成 |
| `/promo-camera` | **商攝導演**：鏡頭、光圈、EV、底片／品牌色彩；三種拍攝模式 |
| `/promo-camera-app` | 同上能力的 **手機 PWA 殼**（共用帳號與點數） |
| `/promo-camera?embed=design` | 從設計頁嵌入開啟（`noindex`） |

成圖存入 **我的數位資產 → 情境圖**。可勾「展示在首頁媒體牆」（免費一般作品無法取消；人像見 §4.1）。

線上副標：**產品、空間、人像攝影模擬**。未登入仍可看介面；拍照需登入並扣點。

#### 5.2.1 商攝導演 — 三種拍攝模式

頂部切 **產品攝影／空間攝影／人像攝影**；深鏈 `/promo-camera/product`、`/space`、`/portrait`。共用相機控制台（空間鎖定圖模式時隱藏相機殼，平視仍可用鏡頭參數）。

| 模式 | 畫面重點 | 計價（以頁面為準） |
|------|----------|-------------------|
| **產品攝影** | 參考圖、主題／場景（選填）、人物／動物（保留／不含／依提示詞）、拍攝角度、描述、輸出長寬比與 MP | 依 MP。免費／方案二一般價；方案三／四每張少 5 點 |
| **空間攝影** | 空間用途、平面配置 → **空間鎖定／空間地圖** →（可選）地圖標註 A–Z → **平視攝影**；另有規劃模擬 | 空間鎖定／平視約 **30 點**／張（2K）；4K 另計 |
| **人像攝影** | 人物參考、**拍攝主題（必填）**、場景、**生成風格**、**衣著**、描述；可加人數／性別、場景參考圖 | 清晰／混合可到 16 MP。氛圍與**實驗**為 1／4 MP。方案三／四同樣 −5 |

相機：**品牌色彩／底片模擬**、鏡頭、光圈、EV、光圈葉片。生成中畫面會顯示「拍攝中…」。

#### 5.2.2 人像 — 生成風格、衣著、審核

**生成風格**（主題／場景／衣著共用）

| 風格 | 流程 | 適合 |
|------|------|------|
| **清晰** | 一次出圖 | 要快、參考與描述已清楚、要臉較像本人 |
| **氛圍** | 草稿（人與場景一起）→ 再套攝影參數／質感 | 商業攝影感、人景較融合 |
| **混合（BETA）** | 先文生空景 → 放入上傳人物 → 再氛圍重拍 | 想先鎖空景構圖與光 |
| **實驗** | 與清晰同一套提示詞，一次出圖（1／4 MP） | 清晰常被外部審核擋下時。**臉部複製程度較低**，較不像原圖本人，也較不容易被當成深偽情色擋下。要高度像本人或證件請用清晰 |

**衣著**（線上按鈕：**原圖衣著／依場景／依描述**）

| 模式 | 行為 |
|------|------|
| **原圖衣著** | 臉、身材與服裝跟參考圖 |
| **依場景** | 只跟人物；衣服依主題／場景 |
| **依描述** | 只跟人物；衣服寫在描述欄（此模式必填描述） |

人像共通（清晰／氛圍／混合／實驗、三種衣著、有無描述、含證件／正式主題都一樣）：**姿勢依場景、不跟原圖姿勢**；構圖預設商用、**不要情色感**。選證件／正式主題時姿勢依該主題（正面正式），不鎖上傳姿勢。畫面說明不會當使用者 prompt 送給模型。實驗模式臉較不像本人，證件認臉請用清晰。

**描述審核**

- `/profile/account.html` 可開關「啟用自動潤飾」（預設開、不扣點）。關掉仍會審查，只是不改寫你打的字。
- 描述空白時不做描述審核。
- 外部生圖 API 另有圖像審核，同一組圖＋場景有時過、有時擋（尤其臥室／躺姿）。
- **被擋時不會**自動改提示詞再送、也不會自動改成依場景。請自行調整參考圖的姿勢與構圖，或把衣著改為依場景後再試。也可改用**實驗模式**（臉較不像本人，較少被當成深偽情色擋下）。說明見 `/help/promo-camera/portrait-modes`（「描述審核與外部擋圖」；該篇發佈後才會出現在 `/help/` 目錄）。

操作說明（發佈後）：`/help/promo-camera/portrait`、`/help/promo-camera/portrait-modes`。

#### 5.2.3 空間攝影 — 兩段式工作流

**Step A — ISO 空間地圖（`layout_plan`）**

1. 選 **空間用途**（住宅／商業等，影響用語）。
2. 上傳或從資產庫選 **平面配置圖**（必填）。
3. 風格：**文字描述** 或 **風格參考圖** 二選一。
4. 選長寬比、**2K（4 MP）或 4K（16 MP）**。
5. 生成 → 得到 **空間鎖定圖／空間地圖**（俯視／型錄視角，圖上無文字；內部亦稱 ISO 地圖）。

**Step B — 平視攝影（`eye_level`）**

1. 輸出類型改選 **平視攝影（對照 ISO）**。
2. 選／上傳 **ISO 空間地圖**（可沿用 Step A 剛生成的圖或資產庫）。
3. **地圖標註**（核心）：在 ISO 圖上打 **A–Z 字母點** → 選 **站點（從）／望向（到）**（預設 B→C）→ 按 **確定標註**。
4. 右側調 **鏡頭／光圈／EV／底片**（會組進提示詞）。
5. 生成 → 得到 **人眼低視角商業攝影**；左側對照仍為 ISO 地圖。

**為何用標註點而非純文字描述？**  
「站在門口看客廳」對模型太模糊；**同一張地圖上的字母座標**能精準對位站點與視向，比空間描述更直觀、更準。

補充：

- 有字母的標註圖可 **下載**、作生圖參考；**不存入資產庫**（入庫仍用原 ISO 圖）。
- 平視主訴求句為平台凍結模板（含捨棄原圖 ISO 視角、低視角等）；成品不應帶字母 overlay。
- 可選 **陳列道具／產品參考圖** 一併送入（與產品／人像模式相同機制）。
- **規劃模擬**：把家具／陳設套進目前空間圖（優先用剛生成的結果）。

## 十二、商攝導演 App（獨立 Store 發行）

商攝導演是 MatchDO **行銷影像**能力中，預定 **另外包成 App 上架**（App Store／Google Play）的一條產品線；**不是**把整站搬進手機，而是聚焦產品／空間／人像攝影 workflow。

| 表面 | 入口 | 狀態 |
|------|------|------|
| **官網工具** | `/promo-camera` | 維持；**凍結**，不為 Store 實驗改壞 |
| **設計 embed** | `/promo-camera?embed=design` | 凍結；手機 embed 可導向 App 殼 |
| **線上 PWA** | `/promo-camera-app` | 獨立 App 介面；可「加入主畫面」 |
| **Store 包** | `apps/matchdo-promo-camera/` | Capacitor；**上架目標**（IAP／deep link 等待續） |

**共用**：MatchDO 登入、點數、`index.js`／`state.js` 生圖邏輯（空間 ISO＋地圖標註＋平視等）。  
**隔離**：Store 專用 `app-runtime.js` 等 **不**掛進線上 PWA；改 Store 需求只動 L4 或三入口共有的 bug 修復。

**與主站分工**

| 主站 MatchDO | 商攝 App |
|--------------|----------|
| 設計稿、素材庫、B 線、媒合 | **僅**商攝／情境影像 |
| `/promo-image/` 情境圖 | App 內可擴充；目前以 `/promo-camera` 三模式為主 |
| 選單「行銷影像 → 商攝導演」 | Store 搜尋／圖示以 **商攝導演** 品牌露出 |

詳 `docs/PLAN-promo-camera-app-isolation-layer.md`、`docs/PROGRESS-promo-camera-app-store.md`、`docs/PLAN-promo-camera-shoot-modes.md`。

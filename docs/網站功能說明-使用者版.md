供 **訪客、訂製者、製造商、產業供應商** 查閱。管理員後台請見 **[網站功能說明-管理員版.md](./網站功能說明-管理員版.md)**。

**操作步驟**請見 `docs/user-manual.md`；**帳號與選單**請見 `docs/account-one-login-capabilities.md`。  
**攝影模擬 App**（Side Project）見 **§十二**。

## 一、網站定位

**MatchDO 合做**是「數位合作市集」：連結 **訂製者（設計／發想）**、**製造商（接單／展示／數位版型）** 與 **產業供應商（上游目錄）**，以 AI 輔助設計、素材管理與行銷影像產出。

| 面向 | 說明 |
|------|------|
| **訂製設計** | 選分類、寫描述、引用廠商版型／材料，生成設計稿 |
| **廠商展示** | 公開首頁展示作品集與素材庫，供訂製者引用 |
| **上游採購（B 線）** | 製造商瀏覽產業供應商目錄，匯入原型組／材料至自己的素材庫 |
| **行銷影像** | 情境圖、商攝導演，供社群、廣告、媒體牆使用 |
| **點數經濟** | 上傳、AI 生圖、重繪、放大、情境合成等依方案扣點 |

### 1.1 主站 vs 攝影模擬 App

| | **MatchDO 主站** | **攝影模擬 App**（Side Project） |
|---|------------------|-----------------------------------|
| **定位** | 數位合作市集全功能 | 行銷影像能力的**手機／Store 發行形態** |
| **帳號** | MatchDO 登入 | **共用**帳號與點數 |
| **入口** | `/promo-camera`、`/promo-image/` 等 | `/promo-camera-app`（PWA） |

詳 **§十二**。

## 二、帳號與選單

### 2.1 同一登入，沒有「角色切換」

| 原則 | 說明 |
|------|------|
| **一個 Email 帳號** | 不區分「訂製者／製造商／供應商帳號」 |
| **①②③ 只是選單分區** | 登入後「我的功能」三區**全部連結常駐** |
| **頁內才做限制** | 資格不足時在頁面或 API 提示，**不從選單隱藏** |

### 2.2 兩項業務限制（一般會員）

| 限制 | 條件 |
|------|------|
| **不可上傳產品與素材** | 免費會員（無有效付費訂閱）不可上傳數位版型與供應商目錄品項；**展示案例**不在此限 |
| **不可匯入供應商目錄** | 製造商須至少 **1 件公開展示中** 的作品案例 |

### 2.3 選單結構

**客製產品 ▾**：產品設計、廠商版型、官方版型、圖樣提取、寫實化、實境模擬、情境圖、商攝導演、材料組合、印花、圖庫、我的數位資產  

**我的功能 ▾**

| 分區 | 主要入口 |
|------|----------|
| **① 訂製／設計** | 控制台、我的數位資產、對話、我的點數、AI 編輯區、材料組合、印花 |
| **② 製造商** | 廠商控制台、公開首頁、展示案例、數位版型、產業供應商目錄、已匯入上游、Embed 訪客紀錄、聯絡方式 |
| **③ 產業供應商** | 上架產品庫、引用紀錄、公開首頁 |

**頭像選單**：帳號資訊、我的點數、商攝導演、聯絡設定。

## 五、① 訂製／設計

需登入。

### 5.1 產品設計

**路徑**：`/custom-product.html`

選分類、描述、參考圖（最多 8 張，可混原型＋材料）；右側資產庫可選材料組合、印花；生成後存至數位資產。

**提示**：產品上要出現的文字請用半形雙引號 `" "` 包住。

### 5.2 情境圖與商攝導演

| 路徑 | 說明 |
|------|------|
| `/promo-image/` | 情境圖（主題／場景 + 產品） |
| `/promo-camera` | 商攝導演（進階相機參數） |
| `/promo-camera-app` | 手機 PWA 殼 |

成圖在「我的數位資產 → 情境圖」；可勾選展示在媒體牆。

### 5.3 材料組合

**路徑**：`/client/material-dual-color.html`

雙色／三色預覽、官方配色範例與「我的配色」、常用材質文字；生圖後進資產庫。

### 5.4 印花

**路徑**：`/client/print-asset.html`

上傳原圖免費；AI 重繪扣點。

### 5.5 我的數位資產

**路徑**：`/client/my-custom-products.html`

| 分頁 | 內容 |
|------|------|
| 設計稿 | AI 協作稿 |
| 情境圖 | 情境圖／商攝產出 |
| 材料組合 | 材料組合紀錄 |
| 印花 | 印花圖稿 |
| 設計風向 | 設計意圖分析 |

每張成圖可開 **生圖履歷**（預覽／匯出 PDF）：入口、參考、prompt、扣點等。

### 5.6 AI 編輯區

**路徑**：`/client/ai-edit.html` — 高解析度 AI 放大等。

### 5.7 其他

| 路徑 | 說明 |
|------|------|
| `/client/dashboard.html` | 控制台 |
| `/client/messages.html` | 站內對話 |
| `/profile/account.html` | 帳號資訊 |
| `/client/find-makers.html` | 找製造商 |

| `/client/industry-suppliers.html` | 瀏覽產業供應商 |

### 6.4 Embed 模擬器（MatchDO Engine）

| 路徑 | 說明 |
|------|------|
| `/embed/simulator.html?…` | 訪客試做 |
| `/client/embed-design-records.html` | 廠商查看訪客紀錄與履歷 |

### 6.5 其他

## 八、點數與 AI 能力

規則見 **方案與定價**（`/subscription-plans.html`）與 **我的點數**（`/credits.html`）。

| 功能 | 誰付點 | 備註 |
|------|--------|------|
| 產品設計生圖 | 訂製者 | 依是否有參考／官方版型 |
| 寫實化、實境模擬、圖樣提取 | 訂製者 | 各工具獨立計費 |
| 情境圖、商攝導演 | 訂製者／製造商 | 1MP 起跳 |
| 材料組合、印花重繪 | 訂製者／製造商 | 上傳印花原圖免費 |
| Embed 生圖 | **廠商** | 訪客免費 |
| 素材上傳、AI 重繪 | 製造商／供應商 | 含 AI 標籤 |
| AI 放大 | 訂製者 | AI 編輯區 |

多數 AI 功能 **失敗不扣點**。

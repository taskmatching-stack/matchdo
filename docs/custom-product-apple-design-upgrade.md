# custom-product.html Apple 風格設計改善

## 改善日期
2026-07-30

## 設計目標
參考 Apple 網站設計邏輯，減少分格線、提升整體感、增加呼吸空間。

## 核心改變

### 1. 去邊框化
- **移除**：所有 `border: 1px solid`、`border-top`、`border-left` 等硬邊框
- **改用**：柔和陰影 (`box-shadow`) 與背景色差異來區分層次
- **效果**：視覺更柔和，不再有切割感

### 2. 增大留白
- **間距統一提升**：
  - 主容器 gap: `2rem` → `3rem`
  - 元素間距：`0.35rem/0.5rem` → `1rem/1.5rem`
  - form-row margin-bottom: `0.75rem` → `1.5rem`
- **效果**：呼吸感更強，不再擁擠

### 3. 圓角升級
- **統一大圓角**：
  - 主容器：`16px` → `20px`
  - 按鈕/輸入框：`6px/8px` → `12-14px`
  - 卡片：`8px` → `14-16px`
- **效果**：更現代、更柔和

### 4. 陰影分層
- **主容器**：`0 4px 24px rgba(0,0,0,.04)` - 極淡
- **懸浮卡片**：`0 8px 24px rgba(0,0,0,.12)` - 明顯但柔和
- **焦點元素**：`0 0 0 4px rgba(0,122,255,0.1)` - 藍色光暈
- **效果**：層次分明，不依賴邊框

### 5. 表單元素背景化
- **輸入框/下拉框**：
  - 去邊框，改用 `background: #f5f5f7`（Apple 灰）
  - 聚焦時變白 + 藍色光暈
- **效果**：與背景融為一體，聚焦時才突出

### 6. 參考圖區塊整合
- **Tab 切換**：背景色區塊（#f5f5f7）+ 白色活動標籤
- **Panel**：無邊框，淺灰背景（#fafafa）
- **縮圖**：增大尺寸（64px → 80px）、間距（0.45rem → 1rem）
- **效果**：更整體，不再有左側邊框切割

### 7. 按鈕優化
- **主按鈕**：藍色漸變 + 陰影 + hover 上浮
- **次要按鈕**：淺灰背景（#f5f5f7）+ hover 變深
- **效果**：視覺層級清晰

### 8. 畫布區域
- **背景**：淺灰（#fafafa）
- **內陰影**：`inset 0 2px 8px rgba(0,0,0,.04)`
- **生成圖片**：大圓角 + 深陰影
- **效果**：凹陷感，突出生成內容

## 文件位置

## 覆蓋策略
- Apple 風格 CSS 最後載入，會覆蓋內嵌 `<style>` 中的舊樣式
- 使用**相同選擇器**確保優先級，必要時可加 `!important`

## 手機版
- **保留**既有手機版邏輯（畫布置頂、底部固定按鈕等）
- **僅調整**：圓角、間距、背景色與桌面版保持一致

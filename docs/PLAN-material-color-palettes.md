### 2.1 選色 UI：手動為主

| 控制 | 誰決定 | 行為 |
|------|--------|------|
| **色數：雙色｜三色** | **使用者手動切** | 顯示 2 或 3 個色號框；切換**不清空**已填 HEX |
| **雙色比重** | **使用者手動切**（僅兩檔固定） | 見 §2.2；即時重畫色卡 |
| **三色比重** | **使用者手動**（可快速預設或**自訂 %**） | 見 §2.3；即時重畫色卡 |
| **色號** | **使用者手動**或按「套用」填入 | 隨時可改 |

### 2.2 雙色比重（固定兩檔，勿自訂）

| Preset key | 顯示名 | 主色 : 配色（上→下） | 備註 |
|------------|--------|---------------------|------|
| `dual_75_25` | 主色主導 | **75% : 25%** | **預設**（維持現行程式／文案／生圖提示） |
| `dual_50_50` | 對半 | **50% : 50%** | |

- 雙色**不做**任意 %；只有上述兩檔。  
- ~~80/20~~ 已否決（太懸殊，2026-08-06）。  
- 實作時：canvas、選色區標註、生圖提示的百分比一律跟選定 preset；預設檔與現況 75／25 一致，無需改預設比例數字，只需加上可切 50／50。

### 2.3 三色比重：自訂為主（手動建立色塊圖）

三色**必須能自訂**主／配／輔三個百分比（上→下）。可另附 1～2 個「帶入數字」的快速預設，但本質是自訂。

#### 手動 UI

| 元件 | 行為 |
|------|------|
| 三個整數％輸入（可加滑桿） | 主、配、輔；建議範圍每段 1～98 |
| 合計列 | 即時顯示；**必須＝100** 才允許「生成」「存成我的」 |
| 「均分」等快捷（可選） | 例如填 34／33／33，**最後一段吃餘數**湊滿 100 |
| 迷你色帶＋大預覽 | 改％或改色號即重畫（純前端，不扣點） |

**驗證（前端＋後端）：** `p1+p2+p3 === 100`（整數）；每段 `>= 1`；否則紅字並停用生成／儲存。

#### 色塊圖怎麼建（Step1，核心）

固定 **1024×1024**、垂直無縫色帶、輸出 **PNG**（與雙色相同，避免 JPEG 分界糊）：

```
h1 = floor(1024 * p1 / 100)
h2 = floor(1024 * p2 / 100)
h3 = 1024 - h1 - h2          // 最後一段吃像素餘數，避免縫隙或總高≠1024
```

繪製：

1. `fillRect(0, 0, 1024, h1)` → 主色  
2. `fillRect(0, h1, 1024, h2)` → 配色  
3. `fillRect(0, h1+h2, 1024, h3)` → 輔色  

**必守：** 三段相接、無灰線、無底色、無文字；預覽可用小 canvas，但**送生圖／待傳的色卡必須用同一套％→像素公式（1024）**。  
共用函式建議：`composeVerticalSwatch([{ hex, pct }, …])`——雙色兩檔與三色自訂都走它。

色塊圖是像素結果；生圖以「看色卡」為準，提示可附帶實際 p1／p2／p3％。**前端不露出模型名。**

#### 存庫欄位（建議）

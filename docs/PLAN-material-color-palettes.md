## 2. 三色預規劃（尚未實作）

### 2.0 必守（2026-08-06 使用者更正）

| # | 規則 |
|---|------|
| 1 | 材料組合材質生成**現行主線＝Gemini 生圖**（路由／點數 key 仍叫 `…flux` 是舊名）。三色規劃談的是**色卡切塊＋生圖提示＋存庫欄位**，**不要**寫成「做 FLUX prompt」。內部備援引擎若有，只留後端，**不進產品敘事**。 |
| 2 | **前端文案／按鈕／提示／Toast 嚴禁出現任何模型名稱**（Gemini、FLUX、BFL、模型 id 等皆禁止）。 |
| 3 | **使用者手動選色／改 HEX／存成我的＝主路徑**。表格「套用」＝把範例色號（與模式／比重）**填進表單**，方便接著手動微調或再存；**不會**自動儲存、**不會**自動按生成。 |

### 2.1 選色 UI：手動為主，切換是使用者操作

| 控制 | 誰決定 | 行為 |
|------|--------|------|
| **色數：雙色｜三色** | **使用者手動切** | 顯示 2 或 3 個色號框；切換**不清空**已填 HEX |
| **比重 preset**（僅三色） | **使用者手動切** | 即時重畫色卡預覽 |
| **色號** | **使用者手動**（picker／打字）或按「套用」填入 | 隨時可改 |
| **存成我的** | **使用者按才存** | 寫入當前色數、各 HEX、（三色時）preset；類型選填 |
| **表格「套用」** | 使用者按 | 填入該列 HEX；若列為三色則**順便把色數／比重 UI 設成與該列一致**（避免套了三色卻還停在雙色框）——這是**對齊表單狀態**，不是自動存、不是自動生圖 |
| **生成材質** | 使用者按 | 才打後端生圖 API |

> 禁止產品敘述用「自動切換」當主軸，以免誤解成系統自己改模式／自己存檔。正確說法：**使用者可切雙色／三色與比重；套用範例會帶入色號並對齊模式。**

### 2.2 三種色塊比重搭配（preset，待定案數字）

垂直色帶（與現行雙色同方向）。下列為**建議預設**，實作前請確認或改比例：

| Preset key | 顯示名（建議） | 主色 : 配色 : 輔色（由上到下） | 用途直覺 |
|------------|----------------|--------------------------------|----------|
| `tri_dominant` | 主色主導 | **50% : 30% : 20%** | 主材大面、配色／輔色點綴 |
| `tri_balanced` | 均衡 | **40% : 35% : 25%** | 三色接近、仍可辨主次 |
| `tri_accent` | 輔色強調 | **45% : 20% : 35%** | 底部輔色較重（滾邊／內裡感） |

- UI：三色模式下再出現 **比重切換**（三顆 radio 或小 Tab），旁附迷你色帶示意。  
- Canvas：依 preset 畫三色無縫色帶（PNG）；生圖提示正向寫明各區百分比（延續雙色「勿加反向詞」原則）。  
- **不做**自由拖曳任意 %（第一版只准三檔 preset）。

### 2.3 資料／API（預留延伸）

| 欄位／概念 | 說明 |
|------------|------|
| `color_count` | `2`｜`3`（表已有） |
| `tertiary_hex` | 輔色（表已有） |
| `ratio_preset`（**新欄，三色時再加**） | 如 `tri_dominant`／…；雙色可 null 或 `dual_75_25` |
| 官方／我的 CRUD | 管理區與「存成我的」在三色模式寫入第三色＋preset（**僅使用者操作時**） |
| 配色範例表 | 三色列多一欄「比重」示意；**套用＝填表單**，不寫庫 |

### 2.4 生圖管線（對齊現行材料組合：Gemini 主線）

| 步驟 | 三色時 |
|------|--------|
| Step1 canvas | 三色色帶依 preset；不扣點 |
| Step2 生圖 | 沿用現有材料組合 API／佇列（**Gemini 主線**）；提示寫「上方 a%／中間 b%／下方 c%」對應三材質——**實作細節在後端，前端不提模型** |
| 印花 | **預設仍「一區擇一」**（主／配／輔擇一）；是否開放需另開需求 |
| 材質輸入 | 第三個材質文字框（輔色區） |
| 扣點 | 可與雙色同 key，或另設（定案時再定）；**UI 只寫「點」不寫引擎名** |

### 2.5 明確不做（三色第一版）

- ❌ 任意百分比滑桿  
- ❌ 水平／斜切／四色  
- ❌ 未確認 preset 數字就寫死進 production 提示  
- ❌ 前端露出模型名稱  
- ❌ 套用範例＝自動存檔／自動生圖  
- ❌ 媒體牆／首頁自動讀圖打標

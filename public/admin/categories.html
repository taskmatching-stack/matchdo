📝 提示詞撰寫方式（為何有些這麼完整？）

為什麼要寫得完整？ 系統會把 AI 的回應當成 JSON 解析，用來顯示「項目、規格、數量、單位」。若提示詞沒要求固定格式，AI 可能回一般文字，前端就無法正確顯示估價表。

你一定要有的：

  1. 角色：一句話說明 AI 是誰（例：你是專業○○顧問）。
  2. 輸出格式：明確寫「請輸出 JSON 陣列」，並列出欄位：item_name（項目名稱）、spec（規格）、quantity（數量，數字）、unit（單位）。
  3. 若該分類有子分類，可寫 {subcategory}，系統會自動替換成使用者選的子分類名稱。

選填但建議加：【分析流程】讓 AI 依步驟思考；【注意事項】可寫單位偏好、無圖片時的處理等。

最精簡範例：

你是○○顧問。依所選子分類「{subcategory}」與用戶描述，列出項目。請只輸出 JSON 陣列：[{"item_name":"項目","spec":"規格","quantity":數量,"unit":"單位"}]，quantity 為數字。
